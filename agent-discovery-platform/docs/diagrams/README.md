# Editable system diagrams

The seven `.mmd` files are Mermaid source. Open them in any Mermaid-capable Markdown editor or paste them into a locally available Mermaid renderer. They require no rendering service or network access to inspect as text.

1. `01-architecture.mmd`: platform, discovery, reasoning, storage, and consumers.
2. `02-discovery-pipeline.mmd`: independent adapters and graceful source failures.
3. `03-identity-resolution.mmd`: conservative identity checks and explanations.
4. `04-shadow-detection.mmd`: multiple behavioral signals and registration checks.
5. `05-capability-matching.mmd`: evidence-aware task matching and exclusions.
6. `06-task-routing.mmd`: execution guards and protocol adapters.
7. `07-end-to-end-sequence.mmd`: the concrete offline demonstration.
