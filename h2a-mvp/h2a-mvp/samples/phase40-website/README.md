# Phase 40 Disposable Website

This small Git project is the real, disposable acceptance target for H2A Phase 40. Providers may edit only `src/**`. H2A registers `package.json`, `.git/**`, `.env*`, and `secrets/**` as protected paths and runs the four package scripts through its command allowlist.

The project is intentionally incomplete. Phase 40 acceptance requires real provider-created diffs, governed research sources, signed handoffs, validation receipts, human approval, and a verifiable integrated commit.
