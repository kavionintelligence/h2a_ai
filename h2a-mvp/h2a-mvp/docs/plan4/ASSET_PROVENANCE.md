# Asset Provenance

- The Phase 36 office visual is original procedural Pixi geometry owned by this project.
- No Munder Difflin sprite, branding, artwork, or source file is distributed. Its repository was used only to study interaction patterns recorded in Plan 4.
- Mosaic was reviewed only as a GPL architectural reference. No Mosaic code or asset was copied.
- The authoritative manifest is `docs/plan4/assets/phase36-asset-manifest.json`; `scripts/verify-phase36-assets.mjs` rejects restricted hashes.
- Lucide icons and installed runtime libraries retain their package licenses in `pnpm-lock.yaml`.
