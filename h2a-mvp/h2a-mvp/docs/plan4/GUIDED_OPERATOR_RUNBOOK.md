# Guided Phase 44 Operator Runbook

## Start

1. Open Demo Gate and choose **New clean session**.
2. Use the displayed launch command to start H2A on that isolated root.
3. Select **Prepare HP demonstration** in Office. Follow its single current action.

## Identity And Withdrawal

1. Enroll the two named participants if the clean root has none.
2. Complete each shared in-place Human Proof dialog when it appears. The dialog closes and canonical eligibility updates automatically.
3. In Authority Inbox create a disposable protected request, then use **Withdraw**. Complete the exact-purpose in-place dialog and confirm a durable withdrawn record in Evidence.

## Ceremony

1. Create the acceptance ceremony and assess prerequisites.
2. Complete organization/bootstrap, real provider and MCP lanes, least-context handoffs, independent approval/resume, two-node federation, six attacks, cancellation, revocation, restart recovery, and governed project integration.
3. Use the Office executive tour for the narrative. Choose **Technical trace** to open the same trace in Control Evidence.
4. Demo Gate must show 11/11, six blocked attacks, verified ledger, clean session, two required-liveness humans, withdrawal evidence, project integration evidence, and `connected-observed` trust.
5. Export the signed package. Run `node scripts/verify-final-acceptance-package.mjs <package-path>` and retain its verified result.

No step requires navigating to Human Proof merely to refresh eligibility, and no manual Refresh is required after a successful shared proof challenge.
