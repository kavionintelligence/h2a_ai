# Phase 51 Operator Acceptance

## Before Starting

1. Use two real enrolled employees and two independent H2A data roots.
2. Confirm Claude, Codex, Antigravity, and the MCP framework are installed and authenticated where required.
3. Open **Workspace → Security map** and select **Start HP demonstration**.
4. When the conductor requests a clean root, open **Control console → Demo Gate**, select **New clean session**, launch the displayed root, sign in again, and select **Start HP demonstration** there.

## Guided Conductor Run

1. At **Lock required liveness**, select **Start/Resume**. H2A enables required mode and stops at the first physical-person boundary.
2. At **Verify two humans**, select the named employee, complete the live camera challenge, then repeat for the second named employee. Photographs and demo bypass do not pass.
3. Select **Resume**. Use **Open required control** for organization authority and workload identity. Confirm separated Administrator/Approver and Operator roles, four active Passport V2 participants, four mandates, and four assignments.
4. Resume into provider work. Run the live Claude, Antigravity, MCP framework, and Codex lanes on the ceremony trace. Complete provider login or consent when shown. Require real output hashes.
5. Resume into least-context work. Seal the protected artifact, issue non-identical grants, run all four handoffs, inspect released and withheld fields, revoke one grant, and prove launch denial.
6. Resume into authority approval. Have the Operator request the protected action and the different Administrator/Approver approve it. Resume exactly once. Retain a rejected request and create a durable withdrawn request with `APPROVAL_INVALIDATED_V2` status `withdrawn`.
7. Resume into federation. On two independent roots use **Connect coworker**, compare the same six-digit code on both screens, complete each named administrator proof, and confirm on both roots. Exchange a task, acknowledgement, and heartbeat; prove replay denial; revoke the peer; prove inactive-peer denial.
8. Resume into governed delivery. Register a real Git project, create one goal, review the work graph, approve it with exact Human Proof, run local and paired agents, cancel and replace one disposable node, validate outputs, route independent integration approval, and integrate the accepted result.
9. Resume into security. Run all six adversarial controls and require persisted blocked receipts. Run operator cancellation and authority revocation. Arm restart recovery, restart H2A on the same root, sign in, and resume the interrupted conductor.
10. Open **Control → Evidence** and reconstruct the ceremony trace. Confirm human, credential, Passport, runtime attestation, mandate, assignment, Context Grant, handoff, decision, output hash, federation, containment, and restart references.
11. Return to **Demo Gate**. Confirm `11/11`, `6/6 blocked`, verified ledger, required liveness for two humans, withdrawal evidence, project integration evidence, and `Connected-observed ceiling`.
12. Select **Resume** once. The host exports the minimized signed package, independently verifies it, mutates a disposable in-memory copy, and records the required tamper rejection.
13. Restart the same root again. Sign in, open Demo Gate, and confirm the conductor remains completed with identical ceremony ID, trace, hashes, receipts, and evidence references.

## Carried UI Checks

1. Deny camera permission, retry, and then complete verification.
2. Present the wrong enrolled person to each identity and require `BIOMETRIC_MISMATCH` rather than a capture-policy failure.
3. Test keyboard-only focus, Escape cancellation, and return focus for proof, coworker, approval, and task dialogs.
4. Inspect Workspace and Control at 390x844, 768x1024, 1024x768, and 1440x900 with no clipping or horizontal overflow.
5. Enable reduced motion and confirm all information remains available without animation.
6. Switch Workspace/Control and compare conductor ID, trace, status, reason code, hashes, and evidence references.

## Final Decision

Only mark Phase 51 complete when every step above is confirmed on the clean root and the release inventory, click-budget verifier, package verifier, and tamper-negative verifier all pass. Record any failure as open; do not substitute automated biometric vectors or seeded ledger data for operator evidence.
